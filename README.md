# PDF Studio

A private, browser-based PDF editor: edit and add text, sign, fill forms, highlight, draw, and merge/reorder/rotate/delete pages.

Everything runs in the visitor's browser. PDFs are never uploaded anywhere.

Built with [pdf.js](https://mozilla.github.io/pdf.js/) (Apache-2.0) and [pdf-lib](https://pdf-lib.js.org/) (MIT).
